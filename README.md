## ✨ Tentang Aplikasi

**OurLoveCouple** adalah aplikasi pasangan berbasis Android yang dibuat untuk membantu pasangan tetap terhubung lewat chat, kenangan, lokasi, catatan, keuangan, AI, dan fitur pribadi lainnya.

Aplikasi ini dibuat dengan tampilan romantis, modern, lembut, dan nyaman digunakan setiap hari bersama pasangan.

---

## 🌸 Fitur Utama

| Fitur | Keterangan |
|---|---|
| 💬 Chat Pasangan | Chat realtime khusus dengan pasangan |
| 🔔 Notifikasi Chat | Notifikasi pesan masuk dari pasangan |
| 📍 Berbagi Lokasi | Melihat lokasi pasangan saat fitur lokasi aktif |
| 🖼️ Kenangan | Menyimpan foto dan momen spesial |
| 📝 Catatan | Membuat catatan pribadi atau bersama |
| 💰 Keuangan | Mencatat pemasukan, pengeluaran, dan ringkasan keuangan |
| 🤖 Asisten AI | Bantuan AI di dalam aplikasi |
| 💌 Pesan AI Harian | Pesan AI personal pada pagi, siang, dan malam |
| 🔋 Status Baterai | Melihat status baterai pasangan saat tersedia |
| 👤 Profil Pasangan | Mengatur profil dan informasi hubungan |
| 🔄 Sistem Update | Update aplikasi melalui GitHub Releases |
