✨ Tentang Aplikasi

OurLoveCouple adalah aplikasi Android privat untuk pasangan yang dibuat agar dua orang bisa tetap terhubung lewat chat, kenangan, lokasi, catatan, keuangan, AI, dan fitur hubungan lainnya.

Aplikasi ini dibuat dengan nuansa romantis, modern, personal, dan nyaman digunakan setiap hari.

---

🌸 Fitur Utama

Fitur| Keterangan
💬 Chat Pasangan| Chat realtime dengan pasangan
🔔 Notifikasi Chat| Notifikasi pesan dengan channel baru dan suara aktif
📍 Berbagi Lokasi| Melihat lokasi pasangan saat fitur lokasi aktif
🖼️ Kenangan| Menyimpan foto dan momen spesial
📝 Catatan| Membuat catatan pribadi/bersama
💰 Keuangan| Mencatat pemasukan, pengeluaran, dan ringkasan keuangan
🤖 Asisten AI| Bantuan AI untuk caption, balasan chat, catatan, dan ringkasan aplikasi
💌 Pesan AI Harian| Notifikasi AI personal pada pagi, siang, dan malam
🔋 Status Baterai| Melihat status baterai pasangan saat tersedia
👤 Profil Pasangan| Mengatur profil dan informasi hubungan
🔄 Update Aplikasi| Sistem update aplikasi dari repository GitHub
